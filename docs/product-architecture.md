# TerraLens Product Architecture

## Core object

The primary object is a **Place**, not a photo.

A Place has:
- identity
- description
- geographic context
- practical information
- one or more community images
- creators/contributors
- social actions
- collections
- trip relationships

## Why this matters

The image is the discovery surface. The place is the durable object.

That prevents TerraLens from becoming only a travel-photo feed.

## Full feature map

### Discovery
Home, Explore, search, category/country filtering, featured places, similar places.

### Community
Upload, image gallery, creators, likes, saves, comments, collections.

### Planning
Trips, trip places, itinerary generation, practical place data.

### Intelligence
AI assistant, itinerary help, similar-place reasoning.

### Business
Affiliate-ready URLs, sponsored-place fields, creator links, future premium flags.
